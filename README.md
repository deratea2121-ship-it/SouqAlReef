# سوق الريف الأول — SouqAlReef

مشروع Android أولي لتطبيق سوق إلكتروني عربي/إنكليزي/تركي.

## النسخة الأولى
- واجهة رئيسية RTL
- بحث
- أقسام متعددة
- إعلانات مميزة
- تبديل الليرة السورية / الدولار
- تنقل رئيسي: الرئيسية، المفضلة، بيع، الرسائل، حسابي

## الخطوات التالية
تسجيل الحساب، إضافة الإعلانات والصور، تفاصيل المنتج، المحادثات، اللغات، الدفع، التوصيل، والإشعارات.
